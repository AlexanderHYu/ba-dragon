# 龙区分与单局称号：算法说明

这份文档一步一步讲清楚分数是怎么算出来的，并附两个从头算到尾的真实例子。为什么这样设计、回测效果如何，见 [rating-design.md](rating-design.md)。

文中的数字都来自当前的模型文件 `src/shared/dragon/model.json`。2026-11 重新校准过：百分位表、卡尔曼参数和实力 ELO 只用 **2026-10-21 以后**的对局，也就是 10 月 20 日 1.2.1 平衡更新之后的数据（10 月 29 日的 1.2.2 只有僵尸活动和修复）。各角色的均值、离散度和单位表仍是 9 月的拟合结果（见第 9 节）。重新拟合后数字会变，公式不变。

## 0. 两套东西

| | 回答什么 | 看不看 ELO | 在哪显示 |
|---|---|---|---|
| **龙区分**（玩家，1~10） | 这个人在他的分段、他的角色构成里算不算强 | 看：和同 ELO、同角色构成的玩家比 | 玩家查询里的龙区分面板 |
| **龙 / 区 / 泯**（单局） | 这一局他打得怎么样（比法同上） | 看 | 上一局、对局档案里名字前的大字 |
| **称号**（单局） | 这一局他对战局实际起了多大作用 | **不看**：高分带低分，功劳就是功劳 | 名字后面的标签，每人一个 |

## 1. 数据

| 接口 | 用来做什么 | 关键字段 |
|---|---|---|
| `/api/players/matches`（最近 20 场） | 玩家龙区分 | 每场全部玩家的赛前/赛后 ELO、摧毁分、损失分、队伍、时长 |
| `/api/analysis/player` | 玩家的生涯角色 | 各兵种类别的花费、最常用的 15 个单位 |
| `/api/match`（单局） | 龙/区/泯、称号 | 上面这些，加上每个单位的出生/阵亡时间、伤害、击杀、补给流向、误伤、游戏的逃兵标记 |

「摧毁分」「损失分」是按单位价值算的分，不是击杀数。接口是 protobuf 转 JSON，值为 0 的字段会被省略（例如缺 `TeamId` 就是 A 队）。

## 2. 角色

单位库里每个单位都有类别和用途，据此分成 7 类：

| 角色 | 包含 |
|---|---|
| 装甲 | 所有载具（坦克、步战车、装甲运兵车、反坦克车） |
| 步兵 | 步兵（单兵防空除外） |
| 侦察 | 侦察类单位，包括无人机 |
| 炮兵 | 支援类里的火炮、火箭炮、迫击炮、战术导弹 |
| 防空 | 支援类里的防空车/防空导弹，加上单兵防空 |
| 直升机 | 武装直升机、侦察直升机 |
| 固定翼 | 攻击机、轰炸机、战斗机 |

卡车、运输直升机、运输机不计入任何角色。

- **单局角色**：用这一局实际出的单位，按价格加权算占比。
- **生涯角色**（用于玩家龙区分）：取生涯各类别的花费，同一类别里再按最常用的单位拆分。比如「支援」拆成炮兵和防空，常用单位没覆盖到的部分，按全体玩家的平均拆分（支援 → 炮兵 37%、防空 44%、其余是卡车），平均拆分的分量相当于该类别花费的 30%。
- 没有数据时，按全体平均构成算：装甲 26%、步兵 16%、侦察 13%、炮兵 10%、防空 14%、直升机 5%、固定翼 17%。

每个人都是混编，所以角色是一组比例，不是单一标签。八成玩家的生涯构成里，正面（装甲 + 步兵 + 侦察）都在 43%～63% 之间，真正以飞机或炮兵为主的人很少。

## 3. 每场的三个量

以下 D = 本人摧毁分，L = 本人损失分。

| 量 | 公式 | 意思 |
|---|---|---|
| K/D | `x_kd = log2((D·k + 200) / (L·l + 200))` | 交换比，取对数是为了让 ×2 和 ÷2 对称；加 200 防止 0 分时算出无穷大 |
| 摧毁贡献 | `x_con = log2((D·k + 200) / (本队在线队员人均 D·k + 200))` | 你在队里打掉的份额，和对局时长、投降无关 |
| 胜负残差 | `S − E`（赢了 S = 1，输了 S = 0） | 比 ELO 预期多赢了多少 |

- **预期胜率**：`E = 1 / (1 + 10^((对方 − 本方) / 400))`。本方、对方各取**在线队员**的赛前平均 ELO，每缺 1 个人，该队按弱 **500 分**算（中途离开的按缺席时长折算）。400 和 500 都是用 4631 局对局拟合出来的，按这个公式，猜赢方的命中率是 65%。
- **阵营（俄 / 美）不计入**：扣掉双方分差之后，283 局随机对局里俄方相当于只多 −5 分（95% 区间 −55 到 +45），看不出阵营本身有优势。
- **占点**：和地图、选位强相关，**不计分**。

### 交换加权（k 和 l）

死什么兵、拿什么兵杀的，分量不一样。这是**设计取舍**（玩家反馈：正面填线的人 K/D 挨罚太狠），不是拟合出来的：

| 兵种 | 击杀倍数（原表） | 损失倍数（原表） |
|---|---|---|
| 装甲 | 1.2 | 0.75 |
| 步兵 | 1.2 | 0.7 |
| 侦察 | 1.1 | 0.9 |
| 防空 | 1.0 | 1.0 |
| 直升机 | 0.9 | 1.0 |
| 固定翼 | 0.8 | 1.1 |
| 炮兵 | 0.75 | 1.4 |
| 运输/后勤 | 1 | 1 |

- **k**（击杀倍数）：本人各单位的击杀数按兵种分摊，加权平均上表；**l**（损失倍数）：阵亡单位按价格分摊（退款回收的不算）。
  这一局没有击杀（或没有阵亡）时，按他的兵种构成（花钱比例）估。列表接口没有单位数据，玩家龙区分直接按生涯构成估。
- 两张表各乘一个缩放系数（击杀 × 0.9719、损失 × 1.1218），让 1199 局 backtest 里全体玩家的 log2 平均倍数为 0：
  **普通人的分数不动，只在兵种构成不同的人之间挪分**。系数由 `scripts/fit-trade.ts` 算出。
- 效果（同一批对局，单局分 1～10）：以装甲为主 **+0.34**、以步兵为主 **+0.32**、混编 ±0、以固定翼为主 **−0.49**、以炮兵为主 **−0.52**；全体平均 +0.005，龙/区/泯变了 7%。
- 第 4 节的角色均值 μ 没有按加权后的 K/D 重新拟合——重拟的话，纯装甲玩家的加分会被自己角色的均值原样吃掉，等于没改。
- 称号（第 8 节）不加权：称号说的是这一局实打实的数字。

## 4. 标准化：和谁比

同样是 K/D 1.0，对炮兵是亏，对装甲是赚。所以每个量先换算成「同类玩家里的位置」：

```
预期值 μ = Σ 角色占比 × 该角色的均值  +  0.28 × (本人 ELO − 这局平均 ELO) / 400  +  (几乎为 0) × (本人 ELO − 2100) / 400
离散度 σ = √(Σ 角色占比 × 该角色的方差)
标准分 z = (x − μ) / σ
百分位   = z 在全体数据里排第几（查分布表）
```

各角色 K/D 的均值（单局口径，括号里是 `2^均值`，即该角色的典型 K/D）：

| 装甲 | 步兵 | 侦察 | 炮兵 | 防空 | 直升机 | 固定翼 |
|---|---|---|---|---|---|---|
| −0.61（0.65） | −0.81（0.57） | −0.14（0.91） | 0.96（1.9） | 1.00（2.0） | −1.03（0.49） | 0.72（1.6） |

- 以炮兵或防空为主的人（占 60%），K/D 1.0 只排在第 21～22 百分位；以装甲、步兵为主的人，K/D 1.0 能排到第 76～82 百分位。
- **分差项**：一个人比同局平均高 400 分时，预期 K/D 要乘 1.21（2^0.28）。被抓进高分局的人会得到相应照顾，在低分局炸鱼的人则要打得更好才算龙。绝对 ELO 本身几乎没有影响。
- 这些均值和离散度用岭回归估出（「共同均值 + 各角色偏离」，偏离量往 0 收缩），收缩强度按玩家分折的交叉验证来选。单局一套（283 局随机排位），生涯一套。

## 5. 单场分与龙 / 区 / 泯

```
单场综合分 c = 0.5 × z_kd + 0.5 × z_con + 0.5 × (S − E) / 0.454
单场分       = 1 + 9 × (c 在全体单场里的百分位)
```

- K/D 和摧毁贡献各占一半；胜负项（实际胜负减 ELO 预期，0.454 是它的标准差）权重 **0.5**。
- 这个权重改过两次，都是设计决定：
  - v1.0.8 及以前是 1（回测里预测之后的「实际胜负 − ELO 预期」最准）。但单局里五个人共享同一个胜负，
    龙/区几乎由输赢决定：历史上输方拿龙的只有 0.4%。
  - v1.0.9 改成 0（输赢是队伍的事）。结果胜率远高于 ELO 预期、但 K/D 一般的人被罚得太狠
    （例：一位 20 场胜率 90%、预期 75% 的玩家从 7.1 掉到 4.4）。
  - v1.0.10 折中为 0.5。
- 每次改权重都重新拟合百分位表和卡尔曼参数（`scripts/fit-outcome.ts`，数据和做法同第 9 节）。回测 121 人：

  | 胜负项权重 | 预测之后「实际胜负 − ELO 预期」 | 预测之后单场表现 |
  |---|---|---|
  | 1 | r = 0.387 | r = 0.546 |
  | **0.5** | **r = 0.380** | **r = 0.591** |
  | 0 | r = 0.342 | r = 0.607 |

  0.5 几乎保住了权重 1 的胜负预测力，又拿到了权重 0 大部分的稳定性。
- 单局里输方拿龙的比例：权重 1 时 0.4%，0.5 时 3.6%，0 时 13%。
- **单场分 ≥ 8.2 标「龙」**（前 20%），**≤ 2.8 标「区」**（后 20%），其余标「泯」。

### 例子：8803400 这局的 ATG（赢）

| 步骤 | 数值 |
|---|---|
| 本局角色 | 防空 24%、装甲 21%、步兵 17%、固定翼 14%、侦察 14%、炮兵 11% |
| 摧毁 / 损失 | 6405 / 3060（K/D 2.09），摧毁是本队在线人均的 1.38 倍 |
| ELO | 本人 2317，本队 2320，对方 2147，全场平均 2234 → 预期胜率 E = 0.730 |
| K/D | x = log2(6605 / 3260) = 1.019；μ = 0.204，σ = 0.725 → z = 1.12（第 89 百分位） |
| 摧毁贡献 | x = 0.453；μ = −0.036，σ = 0.440 → z = 1.11（第 90 百分位） |
| 胜负 | (1 − 0.730) / 0.454 = 0.596（下面是权重 1 时的算法；现在是 0.5） |
| 综合 | c = 0.5 × 1.12 + 0.5 × 1.11 + 1.0 × 0.596 = 1.71 → 第 89 百分位 |
| 结果 | 单场分 1 + 9 × 0.890 = **9.0 → 龙** |

## 6. 玩家龙区分：卡尔曼滤波

把一个人的「真实水平」看作一个随时间可能变化的值，每一场的综合分 c 都是对它的一次带噪声的观测。从最早的一场往最近的一场依次更新：

```
开始：估计 m = 0（普通），不确定度 P = P0 = 0.153
每一场：
  P ← P + q                          （水平可能漂移；这版拟合出 q = 0）
  R = r ÷ min(1, max(0.3, 时长 / 16 分钟))  （单场噪声 r = 1.12；短于 16 分钟的对局噪声更大）
  K = P / (P + R)                    （这一场占多少分量）
  m ← m + K × (c − m)
  P ← P × (1 − K)
```

- P0、q、r、16 分钟这四个数，都是用 591 名随机玩家 10 月 21 日以后的对局序列（每人最近 50 场里更新后的部分，共 19012 场）、按「一步预测似然」拟合出来的。
- **q = 0**：更新后这三周的数据里，看不出一个人的水平在变化。这时卡尔曼滤波等价于「20 场等权平均，再往中间收缩」，**不存在越近权重越高**。以后数据时间跨度拉长，如果拟合出 q > 0，近期对局的权重会自动变大。
- r / P0 ≈ 7.3，相当于分数先天带着「7.3 场普通表现」往中间拉。20 场只能大致定位一个人，所以面板上会显示可能范围。
- 短于 16 分钟的对局（多半是提前投降或有人掉线）会降权，最低降到正常的 30%。

**最终分数** = m 在全体玩家里的百分位（按各 ELO 档的人数加权还原）→ `1 + 9 × 百分位`，所以 5.5 就是中位数。**可能范围** = m ± √P 对应的分数。

| 分数（百分位） | 档位 |
|---|---|
| ≥ 9.1（前 10%） | 🐉 真龙 |
| ≥ 7.3（前 30%） | 有龙样 |
| ≥ 3.7 | 泯然众人 |
| ≥ 1.9（后 30%） | 有点区 |
| < 1.9（后 10%） | 纯区 |

**例子**（ATG 最近 20 场）：按上面的公式依次更新 20 次，最后 m = 0.262，√P = 0.250，排在第 80 百分位 → **8.2，有龙样，可能范围 5.8～9.7**。

面板上的分项（K/D、摧毁贡献、胜负预期）是 20 场各自百分位的平均。「原因」一栏挑出偏离普通最明显的几项，例如「胜率 80%，高于 ELO 预期的 63%」「K/D 中位数超过同角色、同分段 62% 的玩家」。

## 7. 掉线 / 挂机

符合以下任一条件，就判为掉线或挂机：

1. 游戏标记为逃兵（`Deserter`），而且在对局进行到 85% 之前离开（离开时间按最后一次出兵估算）；
2. 整局摧毁分和损失分都是 0；
3. 最后一次出兵早于对局进行到 40% 的时刻，而且摧毁不到本队人均的 15%。

判定之后的影响：

- 掉线的人不计入本队人均，其他人的贡献不会因此虚高。
- 缺人的一方，预期胜率按「每缺 1 人弱 500 分 × 缺席比例」重算，以少打多输了几乎不扣分。
- 掉线的人自己不享受这个减免。
- 「最近对局」接口没有逃兵标记和单位数据，所以玩家龙区分只能用第 2 条判断。

## 8. 单局称号

只看这一局的实际作用，**不看 ELO、不看角色、不看占点**。

**净交换 = 摧毁分 − 损失分**

### 功劳与背锅（每局都会评）

| 称号 | 条件 |
|---|---|
| 大腿 | 赢方净交换最高（不算掉线的人） |
| 背锅侠 | 输方净交换最低；输方有人掉线时，锅直接归掉线的人（他显示掉线狗） |
| 掉线狗 | 第 7 节的掉线/挂机判定 |
| 带不动 | 输了，但净交换是全场第一 |
| 躺赢狗 | 赢了，但净交换为负，而且在全场（不算掉线的人）垫底 |
| 孤勇者 | 本队有人掉线，他是本队净交换第一，而且全场前 3 |

### 突出表现（每种称号一局只给最突出的一个人）

门槛是按真实数据校准的：取 612 局 5v5 排位（9 月采集的 552 局 + 1.2.1 更新后随机抽的 60 局）里「每局最突出的那个人」的数值分布，让每种称号在约 8%～20% 的对局里出现。v1.0.8 之前是 3%～8%，之后是 6%～15%，玩家都反馈太少见；2026-11 把所有目标出现率统一乘 1.3（`titles.ts` 的 `TARGET_SCALE`），有称号的人次从 38.0% 升到 40.8%。只用排位局，是因为随机抽号会抽到剧本、僵尸活动等非对战局，里面零战果的人很多，会把掉线类称号拉偏。表里是当前模型的门槛，由 `scripts/fit-titles.ts --write` 生成。除注明「全部人」的几项外，只在「没掉线、对局 ≥ 8 分钟」的人里评。

| 收割机 | 摧毁分占全场比例最高 | ≥ 17.9% |

### 每人最多显示两个：比谁更罕见

一个人同时符合多个称号时，估计「一个随机玩家在一局里拿到这个称号，而且至少这么夸张」的概率，**概率小的排前面，显示前两个**：

- 突出表现：真实数据里「每局最突出者至少这么夸张」的对局比例 ÷ 10 人；
- 大腿、背锅侠、带不动、躺赢狗、孤勇者：它们的实际出现频率 ÷ 10 人。大腿每局都有，约 1/10；带不动约 2.4%；
- 掉线狗永远优先。

所以大腿如果同时是收割机，收割机排第一、大腿排第二。（v1.0.8 之前每人只显示一个，大腿常被更罕见的称号盖掉。）
鼠标放在称号上会显示这一局的具体数字。

重新校准后的 backtest 统计：每种突出表现称号出现在 5%～14% 的对局里（之前 2%～7%）；
有称号的玩家从 30% 升到 35%——多出来的称号大多落在本来就突出的人身上，这是「每种称号一局只给最突出的一个人」决定的。

**例子**（8803400）：

- 赢方 ATG 净交换 6405 − 3060 = **+3345**，全队最高 → 大腿。
- 输方 Onscreen 3990 − 6635 = **−2645**，全队最低 → 背锅侠。
- Dont 拆了 56 栋建筑，超过 45 的门槛 → 拆迁办。

## 10. 局限

- BATrace 没有「谁打死了谁」的记录，看不出「一个人打两个」这类局部情况；也没有投降投票记录，不知道是谁发起的投降。
- 玩家龙区分的角色用的是生涯花费，而不是每一局的实际出兵（那样每查一个人要多请求 20 次）；也没法按阵营分开统计。
- 玩家部分的卡尔曼、分档线已经换成随机玩家（591 人）；生涯系数（各角色均值）还是 9 月用 179 名分层玩家拟合的。
- 单局百分位表只有 60 局随机排位（566 行），两端的分位有噪声，随机对局多了以后再重拟。
- 更新后只过了三周，数据的时间跨度短，所以看不出水平的变化（q = 0）。
- 1.2.1 之后排位局里有人掉线的比例明显变高（随机排位里 40% 的对局有人掉线，9 月是 28%），和官方公告里说的连接问题一致。

## 11. 实力 ELO

ELO 只看输赢，涨跌慢，龙区分看每局打得怎么样。实力 ELO 把两者合起来，用来回答「这个 2000 分的人实际有多强」：

```
实力 ELO = ELO + 修正值
修正值   = (b0 + b1 × (ELO − 2000) / 500) × (龙区分 − 5.5)
b0 = 44.3，b1 = −3.1（ELO 超出 681～2889 时按边界算）
```

例：2000 分、龙区分 8 → 2000 + 44.3 × 2.5 ≈ **2111**；2500 分、龙区分 3 → 2500 − 41.2 × 2.5 ≈ **2397**。龙区分每高 1 分，实力 ELO 约高 44 分；b1 和 0 没有显著差别，各分段大致一样。

代码在 `src/shared/dragon/effElo.ts`（`effectiveElo(elo, 龙区分)`），参数在 `model.json` 的 `effElo`，由 `scripts/fit-effective-elo.ts` 拟合。

### 怎么拟合

- 数据：1.2.1 之后 60 局随机排位里的 592 名玩家，每人最近 50 场（接口一页最多 50 场）。
- 赛前龙区分：每人每一局，只用**这局之前**的 20 场排位算龙区分，和软件里的算法完全一样。凑不满 20 场的局不用，剩 14463 局（545 人）。
- 胜负预测：`P(本队赢) = 1 / (1 + 10^(−(本队平均实力 ELO − 对方平均 ELO) / 400))`。只有本人的修正值已知，队友按 0，所以本人的修正值在本队平均里要除以本队人数。对 b0、b1 做极大似然。
- 局限：兵种构成用的是采集时的生涯数据，比赛前多了一点信息；同一局可能作为不同玩家的样本出现多次。

### 回测

按玩家留出 30%（173 人、4609 局），参数只用另外 70% 拟合：

| | 对数损失 | Brier 分数 |
|---|---|---|
| 五五开 | 0.6931 | 0.2500 |
| 只看 ELO | 0.6079 | 0.2139 |
| **实力 ELO** | **0.6053** | **0.2127** |

对数损失降 0.0026，按玩家重抽 1000 次的 95% 区间是 0.0008～0.0044，提升可靠但幅度不大。差别主要在龙区分两端：

| 赛前龙区分 | 局数 | 实际胜率 | 只看 ELO 预测 | 实力 ELO 预测 |
|---|---|---|---|---|
| 1～3 | 858 | 45.5% | 49.1% | 45.5% |
| 3～4.5 | 724 | 51.5% | 51.6% | 49.7% |
| 4.5～6.5 | 1064 | 50.9% | 52.1% | 52.1% |
| 6.5～8 | 809 | 56.1% | 52.1% | 53.8% |
| 8～10 | 1154 | 57.9% | 52.5% | 56.1% |

按预测胜率分档，两者的校准都在几个百分点以内，实力 ELO 没有把整体校准变差。

### 验证：之后 ELO 往哪走

如果实力 ELO 是对的，龙区分高的人之后 ELO 应该往上走、低的往下走。每人从第一个有完整赛前龙区分的局开始，看之后最多 30 场（平均 27.7 场）的 ELO 变化，和「真实水平就是实力 ELO」时的预期变化比（每场 K × 胜率差，K ≈ 60，差距随 ELO 追上来而缩小）：

| 赛前龙区分 | 人数 | 平均修正值 | 实际 ELO 变化 | 按主校准预期 |
|---|---|---|---|---|
| 1～3 | 120 | −160 | −8 | −54 |
| 3～4.5 | 78 | −82 | +17 | −28 |
| 4.5～6.5 | 114 | +2 | +7 | +1 |
| 6.5～8 | 83 | +78 | +13 | +26 |
| 8～10 | 122 | +163 | +65 | +53 |

方向一致，实际变化对预期变化的回归斜率 0.64。龙区分高的人涨得和预期差不多；龙区分低的人掉得比预期少，说明低龙区分里有一部分是「打法不吃 K/D」而不是真的弱。
