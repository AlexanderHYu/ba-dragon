# 界面重设计（方案 A · 作战指挥台）

## 目标

现在的界面有人反馈不好看：到处是 emoji，蓝紫渐变、圆角阴影卡片像通用模板，所有功能挤在一个长页面里。
这次换成统一的「作战指挥台」风格，并顺带加几个复盘相关的小功能。

## 配色规则

界面框架只用中性的橄榄灰，颜色只用来表达意思，每种颜色只有一个含义：

| 颜色 | 含义 | 用在哪里 |
| --- | --- | --- |
| 蓝 / 红 | A 队 / B 队 | 队伍标题、3px 色条、整列淡底、每行左边色条、曲线和图例 |
| 金 | 强 | 龙（实心金徽章）、强（金描边）、分数 |
| 骨白 / 灰 | 中等 / 偏弱 | 中、泯用骨白，弱用灰 |
| 暗色 + 虚线 + 斜纹 | 区 | 不用红色，避免和 B 队混淆 |
| 骨白 | 当前选中 | 导航选中项、「你」这一行、主按钮 |
| 绿 / 橙 / 红 | 系统状态 | 只用在状态灯和横幅，红色必须带图标 |

- K/D、胜率这类数字只标两头：明显好的绿色加上箭头，明显差的灰色加下箭头。
- 7 个兵种的颜色：装甲橄榄、步兵灰绿、侦察青、炮兵土棕、防空淡紫、直升机藕粉、固定翼钢灰。都避开蓝、红、金。
- 深色、浅色两套，变量名相同，浅色把金色压暗、斜纹改浅灰。
- 不用 emoji，图标统一用 Tabler 线条图标（`@tabler/icons-react`，打包进软件，不走网络）。
- 直角或 2px 小圆角，不用阴影、渐变和发光。数字用等宽字体。

色值以 `src/renderer/src/styles.css` 顶部的变量为准。

## 布局

左侧固定侧栏替代顶栏。侧栏分三组，底部显示日志、BATrace、录像三个状态灯：

- 对局：当前对局、对局档案、录像
- 情报：玩家查询、单位效能、伤害计算
- 工具：卡组、封禁追踪、设置

原来的主界面（`features/home`）拆掉，每块变成独立页面。复盘页从档案进入，保留「返回」。
窗口较窄（< 1100px）时侧栏收成只显示图标。

## 各页面

- **当前对局**：顶栏显示地图、模式、赛前胜率条；两队左右并排，各铺一层队伍淡底。
- **复盘**：标签页改为 概况 / 玩家 / 单位 / 时间线，默认停在概况。概况顶上放两队对垒条，下面两列：
  左边本局要点、全场之最，右边双方对比、兵种构成。玩家页两队分开两张表，点一行展开单位明细。
- **对局档案**：顶部加近期汇总（近 20 局胜负走势、龙区分、ELO 变化、各标记次数、最常拿的称号），
  加筛选（排位 / 非排位、胜 / 负、按地图或玩家名搜索）。每行左边的色条表示这局你在哪队。
- **录像**：左边播放器和兵力曲线，右边录像列表和录制状态。
- **玩家查询**：左边档案卡（龙区分、可能范围、在同分段里的位置），右边羁绊、常用单位、地图表现、近期对局。

## 新功能

1. **档案汇总和筛选**：只用本地库里已有的数据，不发新请求。
2. **同分段位置刻度**：龙区分本身是百分位，同分段的人在 1–10 上均匀分布，画分布曲线会误导。
   改成一条 1–10 的刻度，按模型的分档阈值（`MODEL.tiers`）分出龙 / 强 / 中 / 弱 / 区五段，
   标出这个人的分数和可能范围。不额外拉数据。
3. **复盘时间线带录像**：这一局有录像时，时间线页上方嵌播放器，曲线和进度条对齐，点曲线跳到对应时间。
4. **关键时刻标记**：每分钟损失明显高于平时的分钟，在曲线和进度条上标出来，悬停显示这一分钟双方损失。

## 不改的东西

- 龙区分、称号、复盘的计算逻辑和 IPC 接口不动，只改界面。
- 设置项不变；`theme` 仍是 `dark` / `light`。
- 冒烟测试里依赖的选择器（`.brand`、`.rp-tab`、`.rp-prow`、`.ctx-menu`、`.replay-row` 等）同步更新。

## 实施顺序

每一步结束都能跑起来、能截图对照：

1. 主题变量换成新配色（保留旧变量名做别名，组件先不动也能整体换色），去掉阴影、渐变、发光、大圆角。
2. 加 `@tabler/icons-react`，写侧栏 `Sidebar`，`Page` 类型扩成各独立页面，拆掉 `Home` 和 `TopBar`。
3. 龙区徽章、分数颜色、K/D 箭头、称号标签按新规则改；去掉所有 emoji。
4. 逐页改布局：当前对局 → 复盘 → 档案 → 录像 → 玩家 → 其余页面。
5. 新功能：档案汇总和筛选 → 位置刻度 → 时间线带录像 → 关键时刻标记。
6. 浅色版逐页检查，更新冒烟测试和使用说明。

## 验收

- `npm run typecheck`、`npm test`、`npm run smoke` 通过。
- 冒烟截图：深色和浅色的当前对局、档案、复盘概况和玩家、录像、玩家查询各一张，和概念图对照。
- 界面文字里没有 emoji（加一个测试扫 `src/renderer`）。
- 同步更新 `使用说明.md` 里讲到界面位置的部分。
